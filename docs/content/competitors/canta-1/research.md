## Why skip

The official [README](https://github.com/samolego/Canta) describes uninstalling “pre-installed or user apps without root” through Shizuku (C3). It offers a web workflow with a data USB cable and Chromium-based browser (C6). That is an Android device-management workflow, not evidence of native Mac storage cleanup. A browser host is not the target device.

Classify as **adjacent software-uninstaller category, excluded for platform/intent mismatch**, not a direct Breathing Room alternative. No Windows support, Mac package removal, process-helper accounting or developer-cache functionality is inferred. An unverified capability is not “No.”

The site's “safe” / “no risk of bricking” language must not become our safety claim. The README explicitly warns that uninstalling critical apps can cause a bootloop requiring factory reset (C4), and mentions stubborn oplus apps. No installation, uninstall, USB connection or recovery test was performed.
