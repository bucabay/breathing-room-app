Sensei Versions

Sensei supported macOS versions all the way back to 10.15 Catalina at launch, but since then we have increased the minimum required macOS version.

If you are on an older version of macOS and the current version of Sensei is incompatible with your system, you can try to use the following version instead:

Download Sensei 1.5.10

Please note that this older version may exhibit more bugs, and we always recommend that you update your macOS and Sensei to the latest version if possible.
