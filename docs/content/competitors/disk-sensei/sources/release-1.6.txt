Sensei 1.6 is now available
Sensei 1.6 introduces a new LaunchDaemon, improved performance, and a unified app. The legacy helper tool is gone, making onboarding faster and more reliable.
We've been working on a major update to Sensei over the last few weeks. This release completely overhauls the internal architecture, improves performance across the board, and fixes some of the more persistent bugs.
A new Background Service Item
Previous versions of Sensei included a privileged helper tool for performing tasks like gathering stats and cleaning files. But the installation process could sometimes fail, leaving users stuck in onboarding.
Sensei 1.6 replaces the helper tool with a modern LaunchDaemon. It’s more reliable, integrates better with macOS, and once approved in System Settings, it just works. No need to re-approve it when updating the app.
The brand new onboarding experience will guide you through approving the item.
One app instead of two
The menu bar Monitor app is now fully integrated into the main app. No more need to start/stop the Monitor. One launch. One experience. Same features.
Laying the groundwork for Sensei 2.0
The new architecture is cleaner, faster, and more future-proof. This update keeps everything you know, while getting rid of the legacy pieces that made updates and bug fixes harder for us than they should’ve been.
Sensei 1.6 is available now as a free update. If you’re already using Sensei, just open the app to get started.
Thanks to everyone who’s supported the app so far. We're just getting started.
Oskar Groth
