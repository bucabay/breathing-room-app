## Workflow article brief — not a draft

**Working title:** Review System Data candidates before trusting a deletion recommendation  
**Slug:** `review-system-data-files-before-smart-check`  
**Intent:** Help a Mac owner turn a file-size result into a deliberate review decision, including the privacy boundary before requesting file advice. Search/reference track, not a renamed comparison matrix.

1. Lead with review/backups and ownership, not a universal 30 GB target or promised recovery.
2. Put the cleared official System Junk visual immediately after the lead; label vendor data.
3. Explain Scan → Browse → Smart Check using documented behavior; no claimed hands-on walkthrough.
4. Ask whether a path/name is sensitive before server-assisted advice. State local versus hosted scope precisely.
5. Review purpose, owner, backups, rebuild/download cost, exact method and subsequent free-space observation. Size is not disposal permission.
6. Use the disclosed Breathing Room Space example later to discuss investigation/ongoing observation, not to invent superiority.
7. State licence, purchase uncertainty and preview caveats before any bounded recommendation.

**Interaction handoff:** a non-mutating checklist—known owner, verified backup, understood rebuild cost, reviewed exact action/method, acceptable metadata sharing. Any unknown stops a deletion recommendation. No forced code demo, synthetic app UI or cleanup execution.
