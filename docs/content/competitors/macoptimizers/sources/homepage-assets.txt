New module
Smart Sort: Automatically sort your Mac files and folders
The module analyzes your source folders, applies predictions (native rules + personalized predictions + learned associations), enriches the results via Spotlight and offers a Mac file organization plan before execution.
Choice of folders, exclusions, scan depth and sorting options.
Source → destination preview, requalification of predictions and validation before organization.
Multi-category scan: documents, images, videos, audio, archives and others.
Unified prediction: learned associations, personalized predictions and weighted native rules.
Additional analysis: Spotlight enrichment and PDF content analysis if necessary.
Execution security: confirmation before moving, optional Finder tags and possible cancellation after organization.
New Premium module
Media Optimization: reduce file size, convert formats, and process media files
The module brings together manual compression and conversion workflows, intelligent space-saving scanning, PDF processing (merger/optimization) and audio/video extraction with queue management.
Video compression with gain estimation, quality profiles and batch processing.
Image, video, audio and PDF conversion with advanced target-format settings.
Batch compress: images, videos, audio, PDF with quality profiles (High, Balanced, Aggressive, Custom).
Convert by file or in bulk: image/video/audio/PDF formats supported with advanced settings.
Dedicated PDF processing: merging several PDFs, optional compression and choice of output file.
Media extraction: extract audio from local video, or video/audio from URL with detailed progress.
Robust queue: pending/in-progress/completed states, timer and overall progress + per file.
New Premium module
Security Scan antimalware: analyze files and detect unwanted potentially dangerous items
The module runs an intelligent security analysis on key locations, displays findings by risk level, and then offers guided actions to isolate potentially dangerous items.
Overview of the module with scan profile selection and quick access to results.
Real-time scan steps with progress, detailed status and instant cancellation.
Detailed findings, multi-selection, quarantine flow and security action history.
Intelligent scan of the most sensitive Mac locations based on selected mode.
Potentially harmful unwanted item detection with severity-based ranking.
Guided post-scan actions: quarantine, controlled deletion, exclusion and review.
Local history of scans and actions for clear security follow-up.
New Premium module
Document Protection: encrypt confidential files in a few clicks
Document Protection lets you encrypt sensitive files so they stay unreadable until you unlock them.
              You manage protected items from a dedicated library and decrypt only when you need to open a document in Finder.
Dedicated library of protected files with locked/unlocked state tracking.
Password confirmation and real-time progress during encryption.
On-demand encryption for sensitive files with `.mcptcrypt` extension.
Manual decryption only when you need to open a file from Finder.
Password required for module access and each sensitive action.
Local history of protected items to quickly find your documents.

Guided repairs from soft to aggressive level with automatic retesting.

Clear escalation to Apple support if not resolved after several attempts.

FAQ
Frequently asked questions
Is MacOptimizers compatible with Apple Silicon and Intel?
Yes. The app works on Apple Silicon (M) chips and Intel Macs.
What versions of macOS are supported?
Ventura, Sonoma, Sequoia and Tahoe are supported.
Is this a real macOS troubleshooting app?
Yes. Diagnostics uses native macOS shell commands, sequential testing, and guided repairs. See also
the Mac diagnostic guide
.
Can I recover deleted files?
Yes. A dedicated recovery module allows you to analyze and then restore the files found.
Can I remove duplicate files?
Yes. The Duplicates section identifies groups and lets you choose which file to keep. See also
the duplicate removal guide
.
How does Smart Sorting work?
The module scans your folders, predicts categories (native + custom rules), suggests destinations, and only moves files after your validation. See also
the Mac file sorting guide
.
What does Media Optimization include?
The Premium module includes 5 modes:
Compress
,
Convert
,
PDF Processing
,
Extract Audio
, and
Extract Video URL
, with queue management and full progress tracking.
What does the Security Scan antimalware module include?
The Premium module analyzes your folders, detects potentially harmful unwanted items, and provides guided actions such as quarantine, detailed review and security history.
What does Document Protection include?
The Premium module encrypts and decrypts sensitive files on demand. As long as a file is encrypted, it stays unreadable until you unlock it with your password.
Is the app free?
Yes, a free version is available. Advanced features are included in the Premium lifetime license (
live price
).
