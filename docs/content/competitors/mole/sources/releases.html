    Mole iterates fast with long-term maintenance. The feature set stays restrained while each capability goes deeper, cleaning more thoroughly and inspecting more carefully.

    v1.18.0 Preview build 338 Download

    1. Uninstall: Choose Uninstall with Mole from Finder’s Services menu to open an app straight in Mole’s list, and its right-click menu in Mole can keep the app and clear only its data.     2. Clean: Caches of Feishu, DingTalk, WeChat’s built-in browser and Codex are covered, and caches of Discord, Slack, Steam, Figma and similar apps are kept while those apps are open. OrbStack, Apple’s container tool, Claude’s virtual machine for third-party providers and Draw Things models now show under Manage Separately, logs Mole cannot remove and background services whose app is still installed are no longer listed, and the scan progress keeps moving with an estimated percentage.
    3. Permission prompts: Scans no longer ask for an administrator password to install Xcode components, and without Full Disk Access neither Clean nor Analyze asks for access to Desktop, Documents or Downloads; Analyze marks those folders as needing access instead of stalling. After a Mole update, the administrator password is asked again only when the action itself changed.
    4. Developer cleanup: Copies of apps Xcode installed on an iPhone or iPad, node_modules in projects untouched for 90 days, caches and indexes of older JetBrains IDE versions, and iOS, watchOS, tvOS and visionOS device support per version are listed for review, along with Instruments session files left after quitting, the old pnpm store in your home folder and simulator runtimes unused for 60 days.
    5. AI cleanup: Cursor’s chat store is listed unchecked, noting that removing it clears all Cursor chats and signs you out. Comfy Desktop’s download cache, old LM Studio engines and the folder left after removing the app, abandoned Codex runtime installs and scratch from finished Claude Code background jobs are found too, with old engines and abandoned installs unchecked.
    6. Updates: Homebrew and App Store updates run faster in Mole: a running app stays open until the install step, Update All installs up to three App Store apps at once, and download progress shows behind a proxy. An app Mole closed for a Homebrew update reopens if the update does not land, App Store checks use your account’s region, bilibili updates from its official package, and Zed, Vorssaint and Folo updates are detected.
    7. Disk analysis: When the disk has grown by 1 GB or more since a map at least a day old, Analyze says so and names the folders and files that grew.
    8. Menu bar and Status: Menu bar readings take only the space they need, and stacked network rates stop shifting. The battery card shows the adapter’s watts, the menu bar panel’s battery rings include this Mac beside its accessories, and memory for system processes such as WindowServer matches Activity Monitor.
    9. License: A Mac left on for weeks no longer shows a license issue after going offline, and when the license server cannot be reached Mole says the license returns once you are online instead of offering Reset, which used up another device slot.
    10. Details: Counters roll smoothly, the faintest grey text is easier to read, more so with Increase Contrast on, closing and reopening the window no longer leaves the old one using memory, VoiceOver and time trackers see which tab is open, startup items launched by scripts are named after their app, removing a backup copy no longer quits the installed app with the same ID or removes its Dock icon, uninstalling Android File Transfer no longer preselects Android Studio’s caches, and uptime no longer rounds up into the next day.
