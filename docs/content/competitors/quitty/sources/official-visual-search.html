All-in-one macOS System Utility

Comprehensive system maintenance, performance optimization, and storage management through a single, unified interface.

System Dashboard

Live CPU, RAM, disk, and battery statistics with visual charts and graphs for system metrics. Smart recommendations for optimization and one-click access to all tools.

System Cleaning

Removes temporary files, caches, logs, and system junk. Trash manager across all volumes and user accounts with smart detection to identify only safe-to-delete files.

File Management

Duplicate file finder with full-system scan support, large files scanner with detailed size analysis, and visual disk space map with interactive directory browsing.

Performance Optimization

RAM booster to free memory by terminating unnecessary processes, real-time CPU monitoring with per-process breakdown, and startup manager to control login items.

Network Monitoring

Real-time upload and download speed tracking with per-application bandwidth usage and active connection analysis.

Automation and Scheduling

Task scheduler for cleaning and optimization routines with daily, weekly, and monthly recurrence options. Idle-time scheduling to minimize disruption.

Advanced Tools

Full app uninstaller with leftover file detection, process manager for viewing and controlling running processes, and detailed hardware and software system information.

Get up and running.

Quick installation steps to get Quitty running on your Mac.

Open Source & Safe

Quitty is completely safe, strictly open-source, and does absolutely zero data tracking.

1. Install via DMG

  1. 1
    Go to the Releases page and download Quitty.dmg.
  2. 2
    Open the downloaded .dmg file.
  3. 3
    Drag and drop Quitty.app into the Applications folder alias.
  4. 4
    Launch Quitty from your Launchpad!

Xcode/Gatekeeper Blocked?

Because Quitty hasn't been signed with a $99/yr paid Apple Developer certificate, macOS Gatekeeper might block it from running the first time.

To bypass Gatekeeper securely:

  1. 1
    Open the Terminal app (Cmd + Space -> type "Terminal").
  2. 2
    Copy and paste this command:
xattr -rd com.apple.quarantine /Applications/Quitty.app

You can now launch Quitty normally!

Option B: Build from Source

To build Quitty yourself, you'll need Xcode 14+ and macOS 14.6+.

  1. 1
    Clone this repository:
    git clone https://github.com/iad1tya/Quitty.git
  2. 2
    Open Bye.xcodeproj in Xcode.
  3. 3
    Select your Mac as the destination.
  4. 4
    Hit Cmd + R to build and run!
