About

The person behind StorageRadar

One person designs, builds, and supports StorageRadar. This page says who that is, which rules the app follows, and how to reach him.

Founder

Vladimir Chemeris

Founder, StorageRadar

Vladimir Chemeris builds StorageRadar, a privacy-first macOS storage analysis app focused on review-first cleanup, developer storage, and before-and-after visibility.

  • He writes the code, ships the updates, and answers support mail himself.
  • StorageRadar sells as a one-time purchase on the Mac App Store and as a Direct build with its own license keys.
  • The app has been on the Mac App Store since April 2026.
Principles

Rules the app follows

Each rule here is checkable inside the app.

Review before removal

The app shows exact paths and sizes before each cleanup step, and a dry run previews what would change. You approve each removal.

Local by default

Scans run on your Mac, and storage data stays there. No account, no cloud sync.

One-time purchase

You buy the User or Developer unlock once. There is no subscription.

Developer-aware cleanup

Dev Cleanup groups Xcode, Docker, simulators, and package caches by ecosystem and risk.

Local AI access

A local, read-only MCP endpoint lets AI tools read scan results. It exposes no file contents and grants no write access.
