Full release history

Every beta build in one place. Use this page for the complete history while the home page stays focused on the product itself.

3.0.8 Release Build 308 2026-10-21
Fixed
  • Treemap and Sunburst show the same legend. Disk Map adds up each category across the whole folder, including items too small to draw. Before, each view counted what it drew, so the two legends disagreed
  • Scans skip virtual volumes such as DeviceFS in ~/Library/Developer/CoreDevice. DeviceFS takes no space on your Mac. Before, scans of your home folder and startup disk counted its contents as part of ~/Library/Developer
  • Folder scans stay on the folder's own volume. Disks and disk images mounted inside the folder appear as empty folders. Scans of the startup disk and of /Volumes keep counting connected disks
  • The Disk Map tooltip hides the item count for folders the map hasn't loaded. Before, a large folder deep in the tree could show “Items 0”
3.0.7 Release Build 307 2026-10-20
Added
  • A heads-up before the first scan when less than 2 GB is free
Improved
  • Clear guidance when your disk is full. If a scan can't save its results because the disk is out of space, StorageRadar now says so and offers Dev Cleanup, App Uninstaller and Open Trash — they free up space without a scan. Before, you saw a generic “Scan failed” error, and Retry failed again
Fixed
  • Closing the App Store payment sheet no longer looks like an error (App Store version). Before, cancelling a purchase could show “Purchase failed”
3.0.6 Release Build 306 2026-10-15
Fixed
  • Scans keep going while macOS asks for access. If macOS shows an access dialog during a Home Folder scan, StorageRadar finishes the scan and lists the folders that didn't open in time. Answer the dialog, then rescan. Before, the scan stayed at 0 files until you answered
  • Categories appear right after a scan. Before, the bar in Disk Overview showed only Other & not scanned until you restarted the app
3.0.5 Release Build 305 2026-10-12
Fixed
  • Docker inside Colima is counted once. When Docker runs in the Colima VM, its images and build cache live on the VM disk that Colima Runtime Data already counts. The Developer caches total added them a second time. The Docker card now shows an Inside Colima VM label
