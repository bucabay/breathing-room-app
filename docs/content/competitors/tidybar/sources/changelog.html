What's new in TidyBar

TidyBar updates automatically (Sparkle). $25 one-time · no subscription - updates are free.

v1.0.2

July 1, 2026
  • Fixed occasional lag and unresponsiveness during normal use - disk-space checks now run off the main thread.
  • The Snapshots and Startup Items panels now open instantly instead of briefly freezing.
  • Smoother disk scanning that no longer stalls the rest of the app.

v1.0.1

June 25, 2026
  • Much faster disk scanning - a new bulk-enumeration engine maps your whole disk in seconds.
  • Large & Duplicate Files now uses far less memory on big scans.
  • More reliable cleanup of long-running tasks and snapshots.
  • Correct whole-disk totals on Apple Silicon (no more double-counting the data volume).
  • Smaller app download and various stability fixes.

v1.0

June 23, 2026
  • First public release of TidyBar.
  • Menu-bar disk cleaner: caches, large files, duplicates, app uninstaller, snapshots.
  • Developer mode: reclaim node_modules, DerivedData, build folders and more.
  • Free to scan; one-time $25 to unlock cleaning. Everything moves to the Trash.
