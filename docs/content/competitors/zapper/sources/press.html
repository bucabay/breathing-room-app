About Mac Zapper

Mac Zapper is a macOS app uninstaller that removes every file left behind when you delete an application. When you drag a Mac app to Trash, macOS only removes the .app bundle — hundreds of hidden files in ~/Library persist. Mac Zapper scans 11 Library directories in parallel, using word-boundary matching to find every related file without false positives.

Built natively in Swift 6 with strict concurrency and SwiftUI, Mac Zapper has zero third-party dependencies. Files are moved to Trash (not permanently deleted), so users can reverse any removal with ⌘Z in Finder.

Unlike subscription-based tools like CleanMyMac ($39.95/year), Mac Zapper is a focused, one-purpose tool: complete app uninstallation, for a one-time $14.99.
