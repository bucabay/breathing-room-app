8 disk-space analyzers for Mac in 2026

Choose a Mac disk-space analyzer by its map, size accounting and removal controls. Eight documented options suit different jobs, not a performance ranking.

Start with the question, not the delete button. DaisyDisk and GrandPerspective suit visual folder investigation. Disk Map adds documented APFS reclaim estimates; DiskFox emphasizes changes between scans. The other choices below address cross-platform habits, relocation, configurable analysis or broader app investigation.

We build Breathing Room, one of the eight. This is an affiliated, documentation-based selection, not independent hands-on testing. Sources were checked October 21–22, 2026; no scan-speed, accuracy or recovered-space benchmark was performed. Inclusion means a documented Mac analysis workflow, not a safety certification. The comparison hub covers the wider choice of approaches.

What each selection earns its place for

1. DaisyDisk: follow a sunburst into a specific folder

Choose DaisyDisk when you want to navigate from a large branch to files you recognize. Its documented map and Quick Look workflow suit manual investigation rather than a list of automatically chosen “junk.” The selection reason is visual navigation, not a claim that its scan is faster.

Don’t use it as a reversible holding bin. Items staged in the Collector remain intact until deletion, but the deletion guide says Delete removes them permanently, not to Trash. Stand-alone and App Store editions also have different administrator/hidden-space capabilities; consult the edition guide before assuming feature parity.

2. GrandPerspective: decide what the rectangles measure

Choose GrandPerspective when you want a focused treemap and control over the size calculation. The official site offers a free SourceForge build and a paid App Store distribution. Its file-size documentation distinguishes logical, physical and tally measures, so you can investigate bytes or unusually large file counts.

Don’t delete a folder just because its visible tiles look expendable. Its preferences guide warns that folder deletion includes hidden, filtered, inaccessible or newly created contents. Disable deletion for an inspection-only session. Older Macs need the separately documented older releases, not the current macOS 14+ build.

3. Disk Map: separate folder footprint from estimated reclaim

Choose Disk Map when the question is “what could this particular action free?” Its homepage documents separate Size on Disk and Space Freed by Deleting concepts for APFS shared data, alongside a treemap and folder table. That distinction is more useful than treating every tile as independently recoverable storage.

Don’t equate reviewed suggestions with guaranteed reversibility. The terms describe actions such as emptying Trash and deleting local snapshots that cannot always be undone. Review the exact method, not just the selected total. Its current macOS 15 minimum rules it out for older systems.

4. DriveScape: use a sunburst across operating systems

Choose DriveScape if you want the same documented scan-and-stage approach on Mac, Windows and Linux. The official page distinguishes free ongoing inspection—maps, lists, trends and duplicate finding—from a cleanup trial followed by a paid licence. That makes it a candidate even if you only want to look.

Don’t treat the website’s risk labels as your backup policy. It documents Trash-first removal and an opt-in permanent action. Rebuilding dependencies still costs time and downloads. Confirm your Mac’s installer requirements first; this shortlist doesn’t establish Intel compatibility or a minimum macOS version for that build.

5. DiskFox: investigate what grew since the previous scan

Choose DiskFox when a static map doesn’t explain why storage keeps disappearing. Its documented workflow connects a scan baseline, dated changes, review, action receipts and regrowth warnings. “Likely” causes are explicitly distinguished from confirmed attribution.

Don’t use an inferred cause as proof an app wrote a particular file. Nor should you assume every action goes to Trash: advanced/permanent methods are labelled separately. Its official product gallery shows Demo Mode sample data, not results from our Mac. The trial is time-limited; this isn’t an indefinitely free viewer.

6. Pangalin Space Manager: consider moving instead of deleting

Choose Pangalin when large libraries or models should live elsewhere, not disappear. Its documented workflow combines inspection with reviewed cleaning, compression and verified moves to an external drive. Free scanning is separate from a per-Mac allowance for changes and the annual licence beyond it.

Don’t choose it for an Intel Mac: the vendor explicitly excludes Intel. Don’t assume all changes are Trash moves either; caches can be cleared directly. Automatic relocation is a separate opt-in mode. On-device Explain has additional macOS 26 and Apple Intelligence requirements, not merely the scanner’s macOS 13 minimum.

7. QDirStat: keep the tree-and-treemap workflow, accept packaging work

Choose QDirStat if you value a directory tree beside a treemap and are comfortable inspecting configurable cleanup actions. Its upstream README lists macOS among target platforms and links a community macOS binary project. That supports inclusion, but not a claim of a first-party Mac distribution with upstream Mac-specific support.

Don’t choose it for a frictionless native-Mac installation promise. Upstream redirects macOS-specific issues to the community distributor. Check that distributor’s current release and architecture requirements, or evaluate a source build. Linux package-manager integration shouldn’t be assumed to work on macOS just because the interface runs there.

8. Breathing Room: add project and app context, accept preview limits

Breathing Room, which we build, fits a broader investigation: category, app/tool, project, folder and large-file views, with app/process context. The current source implements these views; that isn’t certification of every feature in the distributed preview. The local core is free, while agent-assisted investigation requires an authenticated internet connection and can send relevant paths and tool output to the hosted service.

Don’t choose it if you require a production-ready, notarized analyzer or a Python-free installation. The identified preview release discloses Apple Development signing, not Developer ID signing or notarization, plus incomplete clean-machine/physical-Intel validation. Python 3.10+ isn’t bundled. Optional AI Care is paid; exact service allowances aren’t established here. Website download registration and public GitHub release access differ. Don’t disable system protections to install it.

Compare like-for-like sizes before removing anything

Logical size describes file content; physical size describes disk allocation. Neither alone promises the space deletion will release. GrandPerspective documents why sparse VM/container files and online-only cloud items can have large logical sizes but small local footprints. Disk Map separately documents APFS shared-data reclaim estimates. Check the measure before comparing totals between apps.

Scan scope matters just as much. A home-folder scan isn’t the entire disk; protected locations can be skipped. Disk Map explicitly documents optional Full Disk Access and skipped protected folders. A missing folder isn’t empty. Don’t disable macOS protections to make a chart look complete.

Apple’s APFS guide explains that volumes in one container share available space. Apple also says Time Machine snapshot space counts as available storage. Don’t add snapshot totals to file totals and call the result extra reclaimable space, or discard backups merely to reconcile two displays.

Finish with a deliberate sequence: identify the owning app and exact path, verify a usable backup, check rebuild/download costs, then inspect the proposed method. Moving to Trash isn’t immediate free-space recovery. Keep unknown data, rescan the same scope after changes, and compare available space separately from selected-file size. The free storage tools can help reconcile units and a headroom target; they don’t scan or authorize deletion.
