# Screenshot provenance

These are focused crops of earlier Breathing Room browser-preview screenshots,
using example data. They are not live scans of a person's Mac, native-window
captures of the current release, or evidence of space recovered. Some labels and
layout differ from the current preview.

- `home-preview.png`: home storage/app overview, cropped to the main panel.
- `activity-preview.png`: activity metrics and free-space history, cropped to the
  main panel.

The crops omit the older sidebar/footer commercial copy, which no longer matches
the free-app offer. No screenshot content was synthesized or relabeled.
